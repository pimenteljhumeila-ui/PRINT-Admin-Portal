PRINT ADMIN PORTAL - FIGMA-MATCHED FRONT-END

FILES
- index.html: all screens (login, dashboard, orders, price list, service tracking, history, order details, and price editors)
- style.css: visual design, colors, layout, responsive styles
- script.js: navigation, demo login, filters, order detail navigation, status message

OPEN LOCALLY
1. Extract the ZIP.
2. Open the folder.
3. Double-click index.html to run it in Edge or Chrome.
4. Demo login accepts any non-empty username and password.

HOST FOR FREE WITH GITHUB PAGES
1. Sign in to https://github.com.
2. Create a public repository, e.g. print-admin-portal.
3. Upload index.html, style.css, and script.js to the root of the main branch.
4. Go to Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select main and /(root), then Save.
7. Wait for the published URL to appear on the Pages settings screen.

IMPORTANT
This is a front-end prototype using sample data. Login is demo-only and is not secure.
Order status and price saving are visual/demo interactions; they do not persist to a database.
Uploaded-file actions, real order creation, payment, delivery updates, and real administrator
authentication need a backend/database and server-side security.
Please replace sample order details and prices with your actual approved project data.
